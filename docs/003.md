## 从 tdx_local 导入

在 `watchlist.py` 或 `adapters/tdx_local.py` 增加只读解析（不要反向写通达信）：

路径（按序找，命中即停）：

1. `TDX_VIPDOC_DIR` 的上一级 `/T0002/blocknew/zxg.blk`
2. 配置 `tdx.blocknew` / `TDX_BLOCKNEW_DIR`
3. 常见：`/mnt/c/new_tdx/T0002/blocknew/zxg.blk`、`vipdoc` 同级 `T0002/blocknew`

`zxg.blk`：每行 7 位数字，**GBK/latin-1 都试**。

```
首位 1 + 后6位 → 上海  → 600519.SH
首位 0 + 后6位 → 深圳  → 000001.SZ
首位 2 + 后6位 → 北交  → xxxxxx.BJ
```

名称：用现有 `search_stock` / 证券表，找不到则 `未知`。

导入策略：

- Web 子页按钮「从通达信导入」
- **合并不覆盖**：已有记录保留原 `source`；新代码 `source=tdx_local`，`source_file=zxg.blk`
- 可选：同目录其它 `*.blk` 用下拉选板块（显示文件名），默认只导 `zxg.blk`
- 文件不存在：提示路径，不要报栈

CLI（可选）：`czsc-mi watchlist import-tdx`，没有就只做 Web。
