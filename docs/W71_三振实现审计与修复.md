## 一、三振是什么

原文定义（`docs/mistery20260524.md`）：**「三级共振就是大盘 + 板块 + 个股的行情」**。

代码做成**四维**（比原文更严）：个股 30 + 大盘 25 + 行业 25 + 资金 0~20，
并要求 `score ≥ 85` 且资金活跃、大盘向上、行业向上、个股严格腿通过。

链路：

```
build_market_context（指数 K 线 + 行业 up/score）
  → run_mystery → comprehensive_signal_analysis
      → three_resonance_analysis → calculate_resonance_score
  → scorer.combine → AnalysisResult.true_resonance
  → scan_signals.classify / scan_results / Web 真三振池 / Excel·HTML 日报
```

> 命名易混：W68 `wave3.py` 的「三周期共振」（日/周/月位置）与本文「三振」（大盘/板块/个股）是**两个不同概念**。

## 二、W70 审计结论

**框架合理，但核心信号的有效性从未被验证。** 写得严谨，却在真实行情里几乎没被检验过。

### 确认合理

1. **无未来函数**：全部 `iloc[-1]` / `rolling` 默认窗口 / `iloc[-6:-1]` 量比基准。
2. **降级保守**：大盘缺失→0 分、行业 `up=None`→0 分、异常→`is_true=False`，unknown 绝不当 True。
3. **一票否决不被复活**：`basic_filter` 未过 → 综合评分 0；`mix/mpd/pattern` 均在 `base<=0` 时不叠加。
4. **行业腿数据可靠**：生产库板块 K 线 62 万行、成交额 NULL=0、覆盖率 90.5%（4960/5478），实测行业分区分度正常。
5. **落库展示一致**：DB 列 `true_resonance` 与 payload 在 job#94 的 167 只里 167/167 一致。

### 发现的问题

| 级别 | 问题 | 证据 |
|---|---|---|
| P1-1 | **真三振生产历史 0 次触发，且正例零测试** | 全库 `true_resonance=1` **0 行**；因大盘腿要求「向上」，当前 167/167 大盘低位/向下 → 理论最高 `30+0+25+20=75<85`。测试只有 `assert is False` |
| P1-2 | **大盘高位仍可判真三振，与文案矛盾** | `is_true` 未检查「大盘非高位」，仅 -15 软惩罚；四维全过 + 资金 20 + 高位 → `85 → True`，但详情写「大盘非高位」 |
| P1-3 | **signal 与 resonance 双份共振数据分裂** | `pipeline` 把 `three_resonance_analysis` 算两次；`basic_filter` 早退使 `signal.共振评分` 硬编码 0，而 `bd.resonance` 完整算。实测 **75/167 不一致**；日报读 `resonance`、Web/CLI 读 `signal` |
| P2-1 | 三级共振个股腿用宽松 OR，归因写死 | 基础过滤未过却报「三级共振成立（未达真三振：资金/位置条件不足）」，真实原因是个股腿未过 |
| P2-2 | 大盘两套口径 | 三振用 MA20/MA60；更严的 `market_env`（站年线+多头顺次排列）按台账「纯展示不进 scorer」；`fetch_index` 允许 1-3 天滞后 |
| P3 | 行业腿数值对齐 | `closes`/`amounts` 各自 `dropna()` 后独立切片 → 含 NaN 时错位（实证 +0.50 分），生产库无 NULL 故现实影响极小 |

真实数据（生产 job#94，167 只）：真三振 0 / 共振级别「无共振 163、一级 4」/ 大盘位置全低位 /
行业 `up` False 105、True 51、None 11 / `signal.共振评分` mean 2.1、max 58.0。

## 三、W71 修复（本次执行）

**边界**：只收紧 / 纠偏，**不放宽任何触发条件**；不改综合评分公式、不改三类信号、
不改 `AnalysisResult`、不改 `RULE_VER`、不改表结构。

### 1. P1-2 高位硬门闩（`mystery/core/resonance.py`）

`is_true` 由 5 个条件扩为 6 道显式门闩，新增「大盘非高位」：

```python
gates = {'共振评分≥85': ..., '资金活跃': ..., '大盘向上': ...,
         '行业向上': ..., '个股严格腿': ..., '大盘非高位': market_position != '高位'}
is_true = all(gates.values())
reject_reasons = [k for k, ok in gates.items() if not ok]
```

`-15` 软惩罚保留（分数/级别不变），但高位不再判真三振，与详情文案一致。
返回值新增 `gates` / `reject_reasons`，供上层动态归因。

### 2. P1-3 同源 + 去重（`pipeline.py` / `mystery_rules.py`）

- `run_mystery` 只算**一次** `three_resonance_analysis`，同一份结果同时作为 `bd.resonance`
  并通过新增的可选参数 `resonance=` 传给 `comprehensive_signal_analysis` 复用。
- `comprehensive_signal_analysis` 年线早退路径改填**真实**共振字段（评分/级别/建议/资金/最强板块），
  不再硬编码 `0 / 无共振`；但 `综合评分` 恒 0、`真三振` 恒 False（一票否决不被复活，双保险）。
- `scorer.combine` 只读 `signal['综合评分'/'真三振']`，早退在 mix 模式也直接 `return 0.0`，
  故综合评分与顶层 `true_resonance` 完全不变。

### 3. P2-1 三级共振严格腿 + 动态归因（`mystery_rules.py`）

`三级共振` 改用与真三振一致的严格个股腿（评分 `个股共振==30`），
不再用宽松 OR 的 `个股趋势`；`个股趋势` 仅保留作展示。归因改用 `reject_reasons`
列出真实未过门闩，删除写死的「资金/位置条件不足」。

### 4. P3 行业腿对齐（`resonance.py`）

收盘价与成交额按**同一行**对齐后再 `dropna()`；无 NaN 时行为与旧实现完全一致。

### 5. P1-1 正向验证（`tests/test_w71_resonance.py`，27 项）

85 边界正例、四维全过 100 分、高位否决、资金 8/0、各腿缺数据降级、
三级共振严格腿与动态归因、行业腿含 NaN 对齐、`signal`↔`resonance` 同源、
重复计算消除（spy 计数）、综合评分公式不变、**集成链路真触发且有区分度**。

## 四、生产库真实历史回放（回答「信号是不是死的」）

只读脚本 `/tmp/w71_replay.py`：生产库真实上证指数 `sh.000001` 共 **756 根**
（2023-09-14 → 2026-11-03），120 日滚动窗口 step=5 共 128 个，配合理想化的
「个股强 + 行业向上 + 资金满分」评估真三振。

| 指标 | 结果 |
|---|---|
| 大盘向上 **且** 非高位窗口 | **19** |
| 其中真三振触发 | **19（全部）** |
| 大盘不满足窗口里触发 | **0** |
| 大盘向上 **且** 高位窗口 | **42** |
| 其中旧口径会误报 True | **42** |
| 新口径（高位硬门闩）误报 | **0** |

触发样例集中在 2024-09-26 ~ 2024-10-31 的「大盘向上 + 中位」区间。

**结论**：

1. 信号**不是死路径**——合适的市场环境（大盘向上且非高位）下能稳定触发，且有区分度
   （不满足大盘腿的窗口 0 触发）。
2. 生产近期 0 触发是**市场环境**所致，不是代码 bug：最新窗口
   `趋势=向下 位置=低位(pos 1%) close=3608 < MA20=3715 < MA60=3851`。
3. W71 的高位硬门闩在真实历史上拦下了 **42 次潜在误报**，量化了 P1-2 的修复价值。

生产库 5 只真实票（`sh.600519/sz.000001/sh.601318/sz.000651/sh.600036`）实证：
`signal.共振评分` 与 `resonance.共振评分` **100% 一致**（含 4 只年线否决票，综合评分 0 但
共振分已是真实 25，不再硬编码 0）；非否决票 `sz.000001` 综合评分 49.0 不变。
