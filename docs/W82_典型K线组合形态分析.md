# W82 典型 K 线组合形态分析（日 K / 周 K 独立 + 网页配置）（v0.10.41）

## 需求

增加典型 K 线组合形态分析（多方炮、仙人指路等），**日 K / 周 K 单独分析**，
结果在**分析报告（网页 + Excel）**中展示，并支持**网页配置选择形态**。

## 与既有形态模块的边界

| 模块 | 内容 | 是否进分 |
| --- | --- | --- |
| `core/patterns.py` | 头肩/双重/三角形等大级别图表形态 | 展示 |
| `core/patterns_adv.py` | 强势反包阳/缺口/低位地量 | 轻加权（开关控制） |
| **`core/candlestick_patterns.py`（新）** | **10 个经典 K 线组合形态** | **纯展示，绝不进分** |

## 分层实现

### 1. `mystery/core/candlestick_patterns.py`（新增，纯函数零 IO）

- `PATTERN_SPECS` / `PATTERN_CODES` 注册表；
- `detect_combo_patterns(bars, *, period, enabled, lookback, max_hits_per_pattern)`：
  在最近 `lookback` 根内逐根检测，每形态保留最近 2 个命中，
  返回 `{period, lookback, n_bars, enabled, n_hits, hits, summary}`，
  `hits` 含 `code/name/direction/date/detail`，严格 JSON 可序列化；
- `format_summary(hits)`：按形态去重后拼成「多方炮(11-07·多)、红三兵(11-05·多)」，
  避免同一形态连续命中占满报表列；
- `resolve_enabled()`：非法 code 忽略、空 = 全部。

### 2. `mystery/services/runtime_settings.py`（扩展 W76 覆盖层）

新增 5 个配置键（env 名即键名，稀疏覆盖层 `data/candlestick_override.json`，
`MYSTERY_CANDLE_OVERRIDE` 可重定向，显式 env 优先，原子写，删除文件=还原）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `MYSTERY_CANDLE_ENABLED` | `1` | 总开关 |
| `MYSTERY_CANDLE_DAILY` | `1` | 日 K 分析 |
| `MYSTERY_CANDLE_WEEKLY` | `1` | 周 K 分析 |
| `MYSTERY_CANDLE_LOOKBACK` | `60` | 回溯窗口（根） |
| `MYSTERY_CANDLE_PATTERNS` | `all` | 启用形态 code 逗号分隔 |

`candle_options_normalized()` 为全链路单一口径；`candle_cache_tag()` **恒非空**
并入分析缓存键（W73 同款护栏）：改勾选/窗口/开关后旧缓存必失效重建。

### 3. `mystery/services/candlestick_scan.py`（新增）+ 入口接线

- `analyze_candlestick(daily_bars, weekly_bars, options=None)`：
  **日 K / 周 K 分别调用** core 纯函数，异常硬隔离（失败仅返回空结构，
  绝不阻断主分析），产出 `summary_daily/summary_weekly/direction/n_hits/config`；
- `AnalysisResult` 新增 `candlestick` 字段 → `to_dict()` 自动带入
  **日报 / 扫描 payload / Web 个股页**（与 W69 三浪同模式）；
- `AnalysisService.analyze_one_stock` 在组装结果时调用一次
  `_candlestick_result(daily, weekly)`：**daily/weekly 本就在手（周 K 由日 K
  重采样），零额外取数**；缓存命中经 `_result_from_payload` 还原该字段。

### 4. 报告与网页展示（全部只读 payload，不取数不重算）

- **Excel**：`SUMMARY_COLS` 新增 `日K形态 / 周K形态 / 形态方向` 3 列 +
  明细区 `日K命中N / 周K命中N`（带周期前缀，避免同名覆盖）；
- **HTML 日报**：卡片指标加 3 行 + 形态标签（看跌用警示色）；
- **Web 个股页**：新增「典型K线组合形态（日K / 周K 独立分析）」双栏展开区，
  逐条显示形态名称/日期/方向/判据明细，看涨🔴看跌🟢（中国习惯）；
- **Web 扫描结果表**：新增 `日K形态 / 周K形态` 两列（旧 job 显示 `—`）；
- **网页配置**：系统状态页新增「🕯️ 典型 K 线组合形态」面板：
  当前生效 vs 生产默认表格、总开关、日/周开关、回溯窗口、
  **形态多选**（带名称/方向/说明）、保存热生效、🔄 一键还原默认值。

## 约束遵守

- **不改评分 / 信号 / `RULE_VER`**：形态结论仅展示，`scorer.py` 零改动；
- **不打破唯一分析入口**：没有新增入口，只在 `analyze_one_stock` 内附加字段；
- **core 零 IO**：新 core 模块只吃 Bar 列表与注入配置；配置读取在 service 层；
- **报告生成器零取数**：Excel/HTML 只读 `to_dict()`；
- 不引入 `CzscTrader`、不注册大批发信号、不改 `MYSTERY_CHAN_SCORE`。

## 性能

纯计算 O(lookback × 10 形态)，默认 60 根；日/周各一遍，无 IO、无网络。
全市场扫描逐票复用已取 K 线，不重现 W75「收尾逐票取数」卡顿。
