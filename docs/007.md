## W26b — `chip_low` 覆盖率可观测

机制已有，缺的是「看见」和「每个交易日把当天空 turn 填上」。

**默认策略 A（进 18:00）**

- `sync-turnover` 只处理 `--date` 当天、`turn IS NULL`、有 volume、有 `as_of <= date` 的股本。
- 连续 20 个交易日后，有股本的自选近 20 日自然铺满。
- 不回填 `date < as_of`。

**可选策略 B（仅 CLI，不进管线）**

```text
czsc-mi sync-turnover --backfill-days 20
```

仅填 `max(as_of, today-20交易日) ≤ date ≤ today` 的空 turn。单测锁边界；`daily_pipeline.sh` **不传**该旗标。

**QA**

`sync_turnover` 结束打一行结构化日志（或表 `turnover_qa` 当日一行）：

```text
as_of, universe, n_symbols, n_with_shares,
turn_20_coverage, chip_low_unknown_rate,
turn_source{official,legacy,calc_float,ffill,null},
skipped_before_asof, discarded_oob
```

`scan --report` 汇总页脚或两列：`换手20日覆盖率`、`chip_low_unknown只数`。只读，不改排序、不改 2%/低位门。

**落点**

- `mystery/services/sync_turnover.py`
- `mystery/apps/cli.py`（`--backfill-days`）
- 日报组装处（与 W14 单汇总页同一路径）
- `tests/test_turnover_qa.py`（as_of 边界、不覆盖 official、B 不超过 as_of）

**验收**

- 无股本票覆盖率分母不含「无 K」；unknown 语义不变。
- 金标分差 ≤ 1。
- 代码路径无 `v_daily.turnover → turn`。

## W26c — 公司行动触发重拉股本

现有：`--force`、`--watchlist`、周对账、推算股本 >3% 才覆盖。缺：除权日自动打竞价。

**做**

```text
czsc-mi sync-shares --from-adjustments [--since YYYY-MM-DD]
```

- `since` 默认上次成功周对账日，否则近 7 个自然日。
- 从已有 `raw_adjustment_events`（或本仓已同步的复权/公司行动表）筛送转、增发、回购注销、解禁。
- 只对命中 `thscode` 批拉 `auction/snapshot?stage=final`（100/批）。
- 无事件：**零 HTTP**，立即返回。
- 事件日即使股本变化 ≤3% 也写新 `as_of`（新锚点），日志标 `unchanged`。
- 周对账仍用 3% 门槛，避免股价波动误刷。

**管线**

```text
18:00
  czsc-mi sync --period daily --days 365
  czsc-mi sync-shares --from-adjustments   # 无事件秒回
  czsc-mi sync-turnover --date $(date +%F)
  czsc-mi scan --watchlist --report

周日（已有）
  czsc-mi sync-shares --watchlist
```

analyze / Web 仍不打竞价。

**落点**

- `mystery/services/sync_shares.py`
- `mystery/apps/cli.py`
- `scripts/daily_pipeline.sh`
- `tests/test_sync_shares_adj.py`：2 只有事件 + 1 只无事件 → 只请求 2 只；无事件请求数 = 0。

**不做**：用复权因子数值反推流通盘；每日全市场 snapshot。

## 风险

| 风险 | 处理 |
|------|------|
| 调整事件表空或字段不对 | `--from-adjustments` 找不到表则 warn 并跳过，周对账兜底 |
| 竞价限流 | 沿用现有 100/批；事件集通常远小于自选 |
| 覆盖率仍低 | 先看 QA：无股本 vs as_of 偏新 vs oob；对症补周对账，不放开历史回填 |
