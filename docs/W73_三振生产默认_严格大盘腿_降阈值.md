# W73 — 三振生产默认改为「严格大盘腿 + 降阈值」

> 版本：v0.10.32 ｜ 承接：W70 审计建议 5/7 + W72 参数化 ｜ 用户指令：「修改 严格大盘腿 / 降阈值」
> 仓库权威状态见 `DESIGN_DOCUMENT.md` §9（W20–W73）与 §12.11。

## 1. 背景与决策

W70 审计建议 5（大盘腿严格口径 + 指数滞后）与建议 7（重评 85 阈值）在 W72
已完成**参数化 + 金标对拍**，但当时「严格大盘腿 / 降阈值仍不设默认」，需要
先做完整历史回测。W73 把生产默认从 `ma/85` 切换为 **`yearline/80`**。

阈值档位选择依据（与用户确认时唯一做过生产库金标对拍的档位）：

- W72 回放（生产库 `sh.000001` 756 根 100 窗口）：阈值 80/85/90 在
  score 80~100 网格上触发 **21/16/11**；`yearline` 口径下大盘向上窗口
  52→43、真三振触发 17→9（更保守）。
- 故取 **80**：在 score 80~84 区间放行，且降阈值只放宽「共振评分」一道门闩，
  不绕过 W71 高位等其余 5 道硬门闩（`gates` 为 all）。

## 2. 设计原则（与 W71/W72 一致，未破坏）

- 不改综合评分公式、不改三类信号、不改 `AnalysisResult`、不升 `RULE_VER`。
- core 零 IO：env 解析/口径注入仍在 service 层，core 保持纯函数。
- 缓存隔离：口径入 `analysis_cache` 键（W23「改任何一项必 miss」契约）。

## 3. 分层落地（关键：避免破坏既有金标测试）

直接改 `core.DEFAULT_RESONANCE_OPTIONS` 会连带破坏 W71/W72 共 53 项金标测试——
它们的合成指数仅 160 根，`yearline` 要求 ≥250 根会判 unknown、使全部「信号
非死路径」正向验证失效。因此采用分层：

| 层 | 默认值 | 作用 |
|----|--------|------|
| `core.resonance.DEFAULT_RESONANCE_OPTIONS` | `ma / 85` | 库级基线，保护离线金标测试，**不变** |
| `services.analyze.PRODUCTION_DEFAULT_RESONANCE_OPTIONS` | `yearline / 80` | **生产默认**，env 未命中时回退到此 |

`resonance_options_from_env()` 行为变化（W72→W73）：

- W72：无 env → 返回 `{}` → core 回退 `ma/85`，且 `resonance_cache_tag()` 返回 `''`。
- W73：无 env → 返回 `PRODUCTION_DEFAULT_RESONANCE_OPTIONS`（yearline/80）→
  生产默认生效；`resonance_cache_tag()` 基于该默认归一化出**非空稳定 tag**，
  使旧 `ma/85` 缓存不会被新口径命中（W72「默认空 tag」契约在此收紧，属预期内）。

## 4. 门闩与缓存

- 真三振六道门闩（`score≥阈` / 资金活跃 / 大盘向上 / 行业向上 / 个股 OK /
  大盘非高位）`all()` 不回退；降阈值只影响「共振评分≥80」这一道。
- 门闩标签动态渲染：`f'共振评分≥{thr:g}'`，生产默认下自动显示「共振评分≥80」。
- 缓存 tag 示例（无 env）：
  `|R[capital_min_score=8.0|capital_min_volume_ratio=1.5|index_max_lag_days=None|market_mode=yearline|true_threshold=80.0]`

## 5. 回放实证（生产库 `sh.000001` 756 根，2023-09 → 2026-11）

| 口径 | 大盘向上窗口 | 真三振触发 | 说明 |
|------|------------|-----------|------|
| 旧 `ma / 85` | 52 | 17 | W71/W72 生产默认 |
| 新 `yearline / 80` | 43 | **9** | W73 生产默认（更严格） |

- 六道门闩 all() 回归：5 个构造用例（高位/资金不活/大盘向下/行业向下/四维全过）
  全部 PASS。
- 历史高位窗口被新默认否决数 = **34**（>0 证明降阈值未放行高位误报）。
- 指数滞后：最新日 2026-11-03 vs 个股 2026-11-06，lag=3 天；
  `index_max_lag_days=None`（默认）只诊断、不降级，零误伤。

## 6. 一键回退

env 显式设置即完整回退到 W71 基线，且与 `core` 库级基线逐字段相等（测试
`test_w73_回退==core基线` PASS）：

```bash
MYSTERY_RESONANCE_MARKET_MODE=ma MYSTERY_RESONANCE_TRUE_THRESHOLD=85 \
  czsc-mi scan --watchlist --no-persist
```

## 7. 测试与验收

- 新增 `tests/test_w73_production_default.py`：生产默认生效 / env 优先覆盖 /
  缓存 tag 非空且稳定 / 一键回退 == core 基线 / 门闩 all() 不回退。
- 更新 W72 两个旧契约测试（`test_run_rules_passes_env_options_to_pipeline`、
  `test_resonance_cache_tag_default_is_empty`）以匹配新语义。
- 全量：`pytest -q -m "not integration"` → **517 passed, 15 deselected, 0 failed**；
  integration：**9 passed, 6 skipped**。
- 生产库只读回放脚本 `w73_replay.py`（纯只读，不改库）。

## 8. 影响面小结

- 信号语义改变：真三振触发从「宽松大盘腿 + 85 门闩」收紧为「严格年线多头 +
  80 门闩」，生产触发数下降（17→9），符合「更严格」预期。
- Web / CLI / 日报 / 扫描 全链路统一走新默认；旧 `ma/85` 结果因 cache tag
  变更自动失效重建，无口径污染。
- 综合评分、三类信号、`RULE_VER`、写库/缓存/报告兼容层均不受影响。
