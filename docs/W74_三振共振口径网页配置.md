# W74 — 三振共振口径网页配置（运行时覆盖层 + 一键还原）

> 版本：v0.10.33 ｜ 承接：W72 参数化 + W73 生产默认 yearline/80 ｜ 用户需求：「这些参数可以在网页中修改，可以一键还原默认值」
> 仓库权威状态见 `DESIGN_DOCUMENT.md` §9（W20–W74）与 §12.11。

## 1. 需求与方案

W72/W73 已把三振共振口径（`market_mode` / `true_threshold` 等 5 项）参数化，
但修改仍需改代码或 env。W74 让用户**在网页「系统状态」页直接改**，并支持
**一键还原默认值**，无需改代码、无需重启服务。

设计要点：

- **运行时覆盖层文件**：`data/resonance_override.json`（可由 env
  `MYSTERY_RESONANCE_OVERRIDE` 重定向）。网页保存即写入，下次请求热生效。
- **优先级**：显式 env > 覆盖层文件 > 生产默认（`PRODUCTION_RESONANCE_OPTIONS`）。
  运维 env 仍可应急强制覆盖网页设置。
- **core 零 IO 不变**：`resonance_options_effective()` 在 service 层合并，
  core 保持纯函数；非法值仍由 `core.resolve_resonance_options` 兜底。
- **缓存自动失效**：`resonance_cache_tag()` 基于生效口径生成，改口径即换键，
  旧 `analysis_cache` 自动失效重建（W23「改任意一项必 miss」契约）。

## 2. 数据层（mystery/services/analyze.py）

| 函数 | 作用 |
|------|------|
| `RESONANCE_OVERRIDE_PATH` | 覆盖层文件路径（env 可重定向） |
| `RESONANCE_FIELDS` / `RESONANCE_FIELDS_DICT` | 表单字段元数据（单一来源，UI/CLI 复用） |
| `load_resonance_override()` | 读取覆盖层；不存在/损坏 → `{}`，绝不抛错 |
| `save_resonance_override(opts)` | 原子写（先 `.tmp` 再 `replace`），只存已知字段 |
| `clear_resonance_override()` | 删除文件 = 一键还原到生产默认 |
| `resonance_override_exists()` | 是否已自定义（UI 提示） |
| `resonance_options_effective()` | 合并：生产默认 → 覆盖层 → env（优先级递增） |
| `resonance_options_default()` | 当前生产默认（还原目标态） |

`effective` 返回稀疏 dict，交由 `core.resolve_resonance_options` 归一化补齐，
所以 `yearline/80` 与 `ma/85` 等完整口径在 Web 表单默认值里用 `resolve` 后取值。

## 3. Web 面板（mystery/apps/web/views/system.py::render_resonance_config）

「系统状态」页顶部新增配置区：

- **当前生效 vs 生产默认对比表**（含「已自定义 / 默认」状态列）。
- 表单字段：大盘腿口径（ma/yearline）、真三振评分门闩（70–100）、
  资金活跃门槛（评分≥ / 量比≥）、指数滞后降级（开关 + 天数）。
- **「保存配置（立即热生效）」**：写入覆盖层文件，`st.rerun()` 刷新对比。
- **「🔄 一键还原默认值」**：清除覆盖层，恢复 `yearline / 80`。
- 风险提示：改变信号语义；保存后下次分析/扫描即时生效、历史缓存按口径失效重建。

## 4. 热生效验证（无需重启）

```python
# 网页保存 → 覆盖层文件落地 → 下次任意请求 effective 即读新值
import mystery.services.analyze as svc
svc.resonance_options_effective()          # 改前：yearline / 80
svc.save_resonance_override({"market_mode": "ma", "true_threshold": 75.0})
svc.resonance_options_effective()          # 改后：ma / 75（热生效）
svc.clear_resonance_override()             # 一键还原
svc.resonance_options_effective()          # 回到 yearline / 80
```

Web（Streamlit 长驻进程）与 CLI/scan（cron 调用）共用同一文件，口径绝对一致。

## 5. 测试与验收

- 新增 `tests/test_w74_resonance_override.py`（7 项）：覆盖层无/有、save→load 往返、
  effective 合并、clear 还原、env 优先于覆盖层、缓存键随口径变化、损坏文件安全回退。
- 全量：`pytest -q -m "not integration"` → **524 passed, 15 deselected, 0 failed**。
- 覆盖层文件经 fixture 重定向到临时目录，零生产污染。

## 6. 影响面小结

- 仅新增运行时配置能力；综合评分、三类信号、`RULE_VER`、写库/缓存/报告兼容层
  均不受影响。
- 修改是「改信号语义」的高风险操作，故面板含风险提示，且每次改动都因缓存键变化
  自动触发重算，不会出现「旧口径结果被新口径命中」的污染。
- 一键还原 = 删文件，幂等且即时。
