# W87：板块钻取页增加板块分析内容

> 需求：在「板块钻取」中增加板块的分析内容，与每日报告口径一致。
> 版本 `v0.10.45`。

## 一、背景与现状

W85 已实现行业板块关注跟踪与板块研判，`czsc-mi daily` 的 Excel「行业板块」工作表、
HTML「🏭 行业板块研判」区块、以及全量扫描报告都会输出完整的板块分析：年线位置、
MA 排列、5/20 日涨跌、板块强度分、日K/周K 形态、W86 主力建仓吸筹研判、
与板块强相关的个股。

但 **Web 的「板块钻取」页（`views/sector.py::view_sector`）此前只显示一个
「行业强度分（0~25）」指标，然后就是「分析板块成分股 Top10」与「后台扫描全部成分股」
两个按钮**——页面名字叫「钻取」，却看不到板块自身的研判，只钻到了成分股。

W87 补齐这一层，口径与日报完全一致。

## 二、实现

### 1. 纯函数字段映射：`views/sector_fields.py`（新增）

零 Streamlit、零 IO，只做 `analyze_sector` 结果 → 展示值转换，便于单测：

| 函数 | 职责 |
|---|---|
| `sector_drilldown_view(d)` | 概览指标、年线/MA 文字、形态、吸筹等级/阶段/证据/结论，缺字段一律降级 `'—'` |
| `related_stock_rows(rel, results=None)` | 强相关个股明细；传入本期个股结果时按代码归一（`sz.002616` / `002616.SZ` / `002616`）只读关联，补齐评分/建议/吸筹，不重算个股 |

字段映射与 `html_report._sector_block` 同口径：年线文字含偏离百分比、强度分带「偏强/偏弱」、
MA 文字「多头/非多头」、吸筹等级取 `accumulation_level`。

### 2. 视图层：`views/sector.py`

- 新增 `_sector_drilldown_cached(code, name, top_n, corr_window)`：`@st.cache_data(ttl=600)`，
  参数全部可哈希，内部调用 `analyze_sector(db, ...)`；失败降级 `has_data=False`，不抛异常、
  不阻塞原有成分股功能。缓存避免每次 rerun 重算板块指数与成分股的 Pearson 相关矩阵。
- 新增 `_render_sector_drilldown(name, code, ind)`：渲染板块分析内容。
- `view_sector()` 在选中板块后调用它，**原有 Top10 扫描、后台全量扫描、结果表、
  强度表跳转逻辑全部保持不变**。
- 配置来自 `runtime_settings.sector_options_normalized()`（`top_n` / `corr_window`），
  与日报、扫描报告、网页配置面板共用单一口径；读取失败落生产默认 `8 / 60`。

### 3. 钻取页新增的展示内容

| 区块 | 内容 |
|---|---|
| 概览 | 数据日期、板块代码、最新收盘、近5日/近20日涨跌、年线位置（含偏离%）、板块强度分（含方向）、MA 排列 |
| 形态 | 日K形态、周K形态（复用 W82/W83，`analyze_sector` 内由日K聚合周K） |
| 主力吸筹 | 等级、阶段、较近120高点回撤、量能状态、近20日涨跌、四层证据链逐条、结论（W86 同口径，明确「观察区间，非买点」） |
| 强相关个股 | 名称/代码/相关系数/本期已分析/评分/操作建议/主力吸筹；点击 Top10 扫描后命中该股自动补齐后四列 |

无指数 K 线数据时显示提示并回退到原有的「行业强度分」指标，成分股分析照常可用。

## 三、架构约束

- **只读展示**：不取数重算个股评分、不改信号、不改 `RULE_VER`、不改分析缓存键。
- 板块清单仍沿用 `get_sector_meta`，代码由 `analyze_sector` 内部 `normalize_sector_code` 归一，
  不改动成分股查询代码，避免影响 `stock_sector_rel` 关联。
- 强相关个股与本期结果的关联是纯展示层只读映射，不写库、不重算。
- 所有表格列除「相关系数」外统一 `str`，避免 pyarrow int/str 混合告警（W84 经验）。
- 板块分析异常一律降级，不影响原有扫描按钮。
