## 一、策略原文（存档）

### 多周期位置与组合风险

> 增加以下策略扫描。**评估日线、周线、月线位置。**
>
> 同时持有多个高度相关的标的时，**计算组合总风险**。

### 仓位计算公式

> **仓位数量 ＝ 账户总资金 × 单笔风险比例 ÷（买入价格 － 止损价格）。**

### 九、三浪主升交易的九条铁律

> 第一条：只做上升趋势，不做下降趋势。
>
> 第二条：只做有明确第一浪结构的标的。
>
> 第三条：第二浪必须出现合理的调整结构。
>
> 第四条：第二浪调整过程中最好缩量。
>
> 第五条：第三浪必须有明确的向上突破信号。
>
> 第六条：突破最好伴随成交量放大。
>
> 第七条：没有明确止损位置，坚决不买。
>
> 第八条：错过最佳买点，不盲目追高。
>
> 第九条：只做符合交易系统的机会，不为了交易而交易。

### 十、最终交易流程

> 完整流程可以简化为：
>
> 第一步：市场环境筛选。
>
> 第二步：寻找底部反转标的。
>
> 第三步：确认第一浪上涨。
>
> 第四步：等待第二浪回调。
>
> 第五步：观察缩量企稳。
>
> 第六步：等待突破确认。
>
> 第七步：分批买入第三浪。
>
> 第八步：设置保护性止损。
>
> 第九步：跟随趋势持有。
>
> 第十步：根据趋势衰竭信号分批止盈。
>
> **第一浪看趋势，第二浪等机会，第三浪赚利润。**
>
> 不需要每天交易，也不需要抓住所有行情。
>
> 真正值得等待的，是经过第一浪确认、第二浪充分调整、第三浪放量启动之后的高质量趋势机会。

### 免责声明（原文，必须随每次扫描输出）

> **注意：艾略特波浪划分具有主观性，以上条件是交易过滤规则，不代表第三浪必然出现。
> 实际应用必须经过历史回测和模拟交易验证。**

## 二、实现映射

| 原文要求 | 实现 | 位置 |
|----------|------|------|
| 评估日线 / 周线 / 月线位置 | 趋势方向（MA 排列）+ 区间价格分位 + 均线位置 + MA20 斜率 + 三周期共振 | `core/wave3.py::assess_positions` |
| 第一浪 / 第二浪 / 第三浪结构 | 顺序约束 `i0 < i1 < i2 < i3` 的分段极值识别，含涨幅、回撤、量能、企稳门闩 | `detect_wave_structure` |
| 九条铁律 | 逐条判定，硬否决 / 软偏好分开 | `iron_rules` |
| 十步流程 | 状态机，输出当前步与下一步动作 | `workflow` |
| 仓位公式 | 整手取整 + 无止损/除零/上限保护 | `position_size` |
| 组合总风险 | `R = sqrt(ΣᵢΣⱼ rᵢrⱼρᵢⱼ)` + 相关性矩阵 + 风险预算缩放 | `correlation_matrix` / `portfolio_risk` |
| 只读扫描编排 | 本地日 K、日 K 重采样周/月、名称取证券表 | `services/wave3_scan.py` |
| 命令行入口 | `czsc-mi wave3` | `apps/cli.py::_cmd_wave3` |

### 关于「最好」

原文第四条（缩量）与第六条（放量）用了「**最好**」，属于偏好而非硬性条件。
因此默认实现把它们设为 **soft**：只影响 `rule_quality`（0~100 的规则质量读数，
**不是综合评分**），不参与否决；`czsc-mi wave3 --strict` 可升级为硬否决。

### 关于第 9 条（元规则）

「只做符合交易系统的机会，不为了交易而交易」实现为：前八条硬项全过、
且确有第三浪突破信号。策略本就不追求每天出信号——实测三只金标在
2026-11-06 数据下分别为「回避 / 观察 / 回避」，属预期行为。

### 关于衰竭与止盈

第 10 步只在**已突破（第 7 步后）**才可能触发；二浪回调期跌破 MA20 是正常调整，
不会被误判为「趋势衰竭分批止盈」。

## 三、分层边界（重要）

本策略是**独立的交易过滤与风控计算**，不是第二套计分：

- 不产出、不修改 `AnalysisResult.score`，不复用 Mystery 1.22.30 计分规则；
- `mystery/core/**` 保持纯规则零 IO：不 `import czsc`、不联网、不读写数据库；
- 只读扫描不写 `scan_jobs` / `scan_results` / `analysis_cache`，
  不参与 W25 扫描互斥锁，不碰生产 `data/watchlist.json`；
- 周线/月线由本轮同一份日 K `resample_bars` 派生，锁定 `adjust="qfq"`；
- `RULE_VER` 不变，金标三只分数不变，唯一计分入口 `analyze_one_stock()` 不变。

故本次改动**不属于 AGENTS.md §3.1 所禁的「复制规则另出一套分数」**，
无需修改规范文本。

## 四、参数与输出

主要参数见 `DESIGN_DOCUMENT.md` §12.7（`mystery/core/wave3.py::DEFAULTS`）。
每个标的输出：

- 三周期位置明细与共振、趋势允许；
- 三浪结构（各浪起点/高点/低点、涨幅、回撤、量比、突破位）；
- 九条铁律逐条通过情况与否决理由；
- 十步流程当前步、每步状态、下一步动作；
- 买入价、止损价、股数/手数、风险额、市值占比；
- 三态结论：**候选 / 观察 / 回避**；
- 免责声明。

组合层输出：相关系数矩阵、高度相关对、组合总风险、分散比、占权益比例、
`scale_down` 与各候选缩放后的建议仓位。

## 五、使用

```bash
# 扫自选股（默认，纯本地只读）
czsc-mi wave3 --watchlist

# 指定标的 + 资金/风险参数 + 逐条打印铁律与流程
czsc-mi wave3 --symbols sh600519 sz000001 --equity 1000000 --risk-pct 0.01 --verbose

# 全市场（务必带 --limit）+ 严格模式
czsc-mi wave3 --market --limit 200 --strict

# 只看推进到第 6 步及以上的标的
czsc-mi wave3 --watchlist --min-stage 6

# 完整 JSON（含 disclaimer 字段）
czsc-mi wave3 --watchlist --json > wave3.json
```

默认账户总资金 `1_000_000`、单笔风险比例 `0.01`，可用环境变量
`MYSTERY_WAVE3_EQUITY` / `MYSTERY_WAVE3_RISK_PCT` 覆盖。

## 七、W69：合并到扫描结果（2026-11-07）

用户要求「合并到扫描结果中」。W68 的 `czsc-mi wave3` 仍保留为独立只读 CLI，
但**同一套规则自 W69 起已接入 `czsc-mi scan`**，一次扫描即可在 CLI / 日报 /
Web 同时看到三浪结论与组合总风险，无需再单独跑一次策略扫描。

- **落库**：`scan.py::_persist_or_return` 在写库前给每条结果附加 `wave3`
  （精简单票结论）与 `wave3_portfolio`（组合摘要），随 `payload_json` 落
  `scan_results`。表结构不变、无迁移，`scan_results_of` / 日报 / Web 直接可读；
  组合摘要挂在每一行，`--signal` 过滤后仍可读到；`--resume` 收尾同样附加
  并回写 `payload_json`。
- **展示**：CLI 逐票 `三浪=` + 末尾固定输出组合摘要与免责声明；Web 扫描表
  新增 10 列 + 表头下一行组合摘要；日报 Excel 加 10 列 + QA 摘要行，HTML
  卡片加 8 项指标与「三浪候选」标签 + 头部摘要行。旧任务缺字段显示 `-`。
- **边界不变**：只读评估、不改综合评分 / 三类信号 / `AnalysisResult` /
  `RULE_VER`，不写生产自选股；整体异常硬隔离，失败不影响既有扫描结果。
- **开关**：`MYSTERY_SCAN_WAVE3`（默认 1，0=关闭）、
  `MYSTERY_SCAN_WAVE3_MAX`（0 不限，>0 只评估按分降序前 N 只）、
  `MYSTERY_SCAN_WAVE3_STRICT`（默认 0）。资金/风险比例沿用 W68 env。

完整字段表与参数见 `DESIGN_DOCUMENT.md` §12.10 与 §9 的 W69 台账行。
