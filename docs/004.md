# chip_low 口径落地（名实相符）

只改扫描标签，**不改综合分、不拉新 K、不重算 VAP**。  
入口仍是 `analyze_one_stock` + `classify(to_dict())`。

---

## 口径（写死）

`chip_low = True` 当且仅当：

1. 缩量：`turnover_20 < 2`（没有 `turnover_20` → 不是 chip_low，见下）
2. 低位（任一即可）：
   - `mystery.platform.平台状态` 含「平台内」或明确「未远离 / 未突破离场」（按现有中文字段 `.get`，对不上就当这门未过）
   - **或** 现价相对近 120 日最高价回撤 ≥ 15%  
     `price_pos = 1 - price / high_120`，`price_pos >= 0.15`

否则：

- 无 `turnover_20`（及旧兜底路径都没有）→ `chip_low=False`，`chip_low_unknown=True`
- 有换手但 &lt;2% 且不满足低位 → `chip_low=False`，可加 `chip_quiet=True`（高位缩量，不进 chip_low 过滤）
- 换手 ≥2% → 两者都 False

禁止 unknown 当 True。

`high_120` 在 **analyze 阶段**用已有日 K 算好，写入结果顶层，与 `turnover_20` 一样：

```text
high_120: Optional[float]   # 近 120 根日高的最高价
```

`classify` 只读 `d["high_120"]`、`d["price"]`、`d["turnover_20"]`、`d["mystery"]["platform"]`。
