# W84：各大指数分析（日报 + 全量后台分析纳入）

## 背景
用户要求：
1. 每日报告增加各大指数的分析；
2. 全量后台分析也把各大指数加入进去。

此前只有「上证指数」作为共振锚点（`_INDEX_CODE`），其余宽基指数从未同步，
日报与扫描结果里看不到各大指数本身的走势研判。

## 实现

### 1. 新增 `mystery/services/index_analysis.py`（核心，零 IO）
- `MAJOR_INDEXES`：8 大宽基指数（名称 + 内部代码）
  `上证指数 000001.SH / 深证成指 399001.SZ / 创业板指 399006.SZ / 沪深300 000300.SH /
   上证50 000016.SH / 中证500 000905.SH / 科创50 000688.SH / 中证1000 000852.SH`
- `analyze_index(market, name, code)`：对单只指数做纯价格研判，返回可序列化 dict：
  - `close` 最新收盘、`chg_5d` / `chg_20d` 近 5/20 日涨跌幅
  - `above_year` / `year_dist_pct`：年线（250 日）位置（突破=收盘>MA250）
  - `ma_aligned`：MA 多头排列（MA5≥MA10≥MA20≥MA60）
  - `candle_daily` / `candle_weekly`：日 K / 周 K 典型组合形态（复用 W82/W83 core 检测器）
  - `has_data`：缺数据降级为 False，结论字段置 None，绝不抛异常
- `analyze_major_indexes(market)`：遍历 MAJOR_INDEXES；无数据的指数仍保留在列表。
- `index_summary_line(idxs)`：一行文字摘要（头部 QA / 飞书正文同口径）。

### 2. 日报接入（`mystery/apps/cli.py :: _cmd_daily`）
- 报告生成前用共享 `svc.market` 计算 `analyze_major_indexes`，作为参数传给
  `write_excel` / `write_html`（新增 `major_indexes` 形参）。

### 3. 报告渲染
- **Excel**（`excel_report.py`）：`major_indexes` 非空时新增「各大指数」工作表
  （指数 / 代码 / 最新收盘 / 涨跌幅5日 / 涨跌幅20日 / 年线位置 / MA排列 / 日K形态 / 周K形态）。
- **HTML**（`html_report.py`）：个股卡片前渲染「各大指数研判」表格区块
  （年线位置红绿配色 + 日/周 K 形态列），并补 `.idx-table/.up/.down` 样式。

### 4. 全量后台分析接入（`mystery/services/scan.py`）
- `scan_market` 在 `scan_type in ("market","full")` 口径下，扫描收尾时把 8 大指数
  以 `is_index=True` 标记并入 `results`：
  - 通过 `payload_json` 直接落库（`scan_results` 表无需新增列/迁移）；
  - `_attach_wave3` 跳过 `is_index` 条目（指数为纯价格，无从做三浪）；
  - 自选 / 板块扫描（`watchlist` / `sector`）不含指数，避免污染个股池语义。
- `_write_scan_report` 将指数条目抽离为报告独立区块，个股结果只传股票，不进入个股卡片/排序。

### 5. Web 扫描表（`mystery/apps/web/views/scan.py`）
- 新增「类型」列（指数 / 个股，位于代码之后，不影响 W76「名称在前」列序）与
  「指数研判」列（年线位置 + MA 排列，仅指数行有值）。

## 数据来源
- 8 大指数经既有 `MarketDataClient.fetch_index` 取数：DB 优先（上证指数已在库），
  其余首次分析走 `ths_official` 在线补齐并**自动落库**，之后命中本地库；
  在线失败则降级为 `has_data=False`，报告/扫描不阻塞。

## 约束（与 W82/W83 一致）
- 零 IO：所有取数通过传入的 `MarketDataClient`，本模块不直接碰库/网络；
- 纯价格：指数无换手/行业/财务，只做价格面研判；
- 不改评分、不动 `rule_ver`、`MYSTERY_CHAN_SCORE=0`、不引 `CzscTrader`。

## 验证
- `pytest -m "not integration"` 全量 **628 passed, 0 failed**（含 8 个 W84 新增用例）；
- 集成冒烟：`scan_market(limit=2, no_persist=True)` 返回 10 条 = 2 个股 + 8 指数，
  指数条目 `is_index=True` / `score=None` / `index_analysis` 字段齐全；
- 真实数据实测：8 大指数全部研判成功（截至 2026-11-09 全线处于「跌破年线/非多头」）。
