# W85：行业板块关注跟踪 + 板块分析（日报）

> 版本 v0.10.43 · 需求：「支持选择行业板块关注跟踪，并分析与板块强相关的个股，在每日分析中增加板块的分析」

## 一、数据来源（全部只读，无需新增同步）

生产库已有完整板块数据体系：

| 表 | 规模 | 用途 |
|---|---|---|
| `sector_meta` | 708 个板块 | 板块元数据（名称 / 类型 / 启停） |
| `sector_kline` | 621,483 行 / 688 个板块 / 931 根日K | **真实板块指数 K 线**，最新 2026-11-09 |
| `stock_sector_rel` | 10,033 行 / 302 个板块 | 个股-板块归属（`is_primary=1` 主行业） |
| `sector_constituents` | 0（空，兜底用） | 成分股备用 |

关键约束：**板块强度禁止成分股抽样，只用 `sector_kline` 真实指数**（沿用 `adapters/sector.py` 的既有口径，复用 `core.resonance.calculate_industry_score_from_sector`，0~25 分、>12.5 偏强）。

代码归一：`881101.TI` / `881101` / `ths_881101` → `ths_881101`（`normalize_sector_code`）。
881 行业板块名称不在 `sector_meta` 里，直接取 `sector_kline.sector_name`。

## 二、新增模块 `mystery/services/sector_analysis.py`

| 函数 | 职责 |
|---|---|
| `list_sectors(db)` | 可选板块清单（仅返回有 ≥30 根真实指数 K 线的板块），带名称 / 成分股数 / 最新日期 |
| `resolve_focus_codes(db, focus, results, auto_max)` | 解析关注板块：`auto`（默认，跟随当期分析标的主行业，按频次取 topN）/ `all` / 显式 code 列表 |
| `analyze_sector(db, code, ...)` | 单板块研判：年线位置、MA 多头排列、5/20 日涨跌、板块强度分、日/周K组合形态、主力吸筹(W86)、强相关个股 |
| `analyze_focus_sectors(db, opts, results)` | 日报/扫描报告统一入口，返回 JSON 可序列化 dict 列表 |
| `sector_summary_line(sectors)` | 一行摘要（写入 QA / 飞书正文） |

**强相关个股**：板块指数 `pct_change` 与成分股近 N 日收益率求 Pearson 相关系数，取 topN；相关系数有效重叠样本 <15 日则跳过，绝不编造。若个股在本期分析结果中，附带评分 / 操作建议 / 吸筹结论（只读，不重算个股）。单板块成分股上限 250 只（`CORR_MAX_STOCKS`）作为性能护栏。

**周 K**：`sector_kline` 只有日线，按自然周 `resample('W-FRI')` 聚合 OHLCV 生成周 K（真实数据重采样，不造数、不抽样），再喂 W82 形态检测。

## 三、网页配置（`views/system.py` → `render_sector_config`）

复用 W76/W82 的「稀疏覆盖层 + env 优先 + 一键还原」机制，写入 `data/sector_override.json`：

| 键 | 默认 | 说明 |
|---|---|---|
| `MYSTERY_SECTOR_ENABLED` | `1` | 板块分析总开关 |
| `MYSTERY_SECTOR_FOCUS` | `auto` | auto / all / 逗号分隔 `ths_` 代码列表 |
| `MYSTERY_SECTOR_TOP_N` | `8` | 每板块强相关个股数 |
| `MYSTERY_SECTOR_CORR_WINDOW` | `60` | 相关性窗口（交易日） |
| `MYSTERY_SECTOR_AUTO_MAX` | `8` | auto 模式最多板块数 |

面板提供：当前生效值对照表、总开关、关注来源单选（auto / 手动多选（支持名称搜索）/ all）、三个数值输入、保存热生效、一键还原默认值。板块清单来自 `list_sectors`（688 个，881 行业段排前）。

## 四、日报与报告层接入

- `cli.py::_cmd_daily` 与 `_write_scan_report`：分析完成后调用 `analyze_focus_sectors`，摘要追加到 QA 行，并把 `focus_sectors` 传给 `write_excel` / `write_html`。板块分析失败被 try/except 兜住，**不影响个股报告主体**。
- `excel_report.py`：新增 `focus_sectors` 参数；「行业板块」工作表分两区——板块研判 14 列（含年线/MA/强度分/日周K形态/主力吸筹）+ 强相关个股明细 8 列（相关系数 / 本期已分析 / 评分 / 建议 / 吸筹）。
- `html_report.py`：新增「🏭 行业板块研判」卡片 + 每个板块可展开的「吸筹证据与 N 只强相关个股」明细表。
- 「各大指数」表与 W86 吸筹列一并扩展（见 W86 文档）。

## 五、性能与验证

- 真实数据端到端：8 个 auto 关注板块约 **4.4s**；3 只个股 + 8 指数 + 3 板块生成日报，Excel 三个工作表、HTML 各区块齐全。
- `tests/test_w85_sector_analysis.py` 14 项全绿；全量非集成回归 **654 passed, 0 failed**。
- 架构约束保持：core 零 IO；报告生成器只读传入的 dict，不取数、不重算；不改评分 / 信号 / `RULE_VER`；不写业务库；历史 scan job 结果不回填。
