# W72 三振共振口径参数化（审计建议 5 / 7）

> 版本 0.10.31 · 提交 `main` · 对应《三振实现审计报告》建议 5、建议 7。
> 设计原则：**默认逐字段等价 W71/0.10.30 + 显式开关 + 真实历史金标对拍**。
> 不升 `RULE_VER`、不改综合评分公式、不改三类信号、不改 `AnalysisResult`。

## 一、背景

W70 审计发现三振（`true_resonance`）实现「框架合理但核心信号有效性从未被验证」，
列出 7 条建议。W71 落地了低风险的建议 1/2/3/4/6（收紧/纠偏），并明确把
**会改变信号语义**的建议 5、建议 7 保留待拍板：

- **建议 5**：明确大盘腿口径（接入 `market_env` 的严格多头定义），处理
  `fetch_index` 允许 1-3 天滞后与个股日期对齐。
- **建议 7**：重评 `85` 阈值与「资金 ≥8」隐含门槛；或把「大盘向上 + 行业向上
  + 个股通过」的三维成立单独暴露为可过滤的「三级共振」信号。

用户「确认修改」后，W72 以「口径参数化 + 开关 + 对拍」落地这两项，
**生产默认值一律不变**——切换口径属于改变信号语义，按审计要求须先做
完整历史回测与模拟交易验证，不擅自设默认。

## 二、实现

### 分层与零 IO

| 层 | 文件 | 职责 |
|---|---|---|
| core 纯规则 | `core/resonance.py` | `DEFAULT_RESONANCE_OPTIONS`、`resolve_resonance_options`（非法值保守回退）、`analyze_market_trend_yearline`、`index_lag_days`；`calculate_resonance_score` 阈值参数化、`analyze_capital_flow` 资金门槛参数化 |
| core 编排 | `core/mystery_rules.py` / `core/pipeline.py` | `three_resonance_analysis` / `comprehensive_signal_analysis` / `run_mystery` 增加 `options` 透传，结果附纯增量诊断字段 |
| core 信号 | `core/scan_signals.py` | 三级共振只读暴露为 `filter_by_signal` 可过滤项（不改 `classify` 返回契约） |
| service | `services/analyze.py` | `resonance_options_from_env()` 读 5 个 env → 注入 core；`resonance_cache_tag()` 口径入缓存键 |
| CLI | `apps/cli.py` | `--signal` 新增 `three_resonance` |

`core` 保持零 IO：不读 `os.environ`、不查库、不联网。口径由 service 层搬运。

### 建议 5：大盘腿双口径

- 默认 `ma`：W71 现状，收盘 > MA20 且 > MA60 判「向上」，近 120 日分位判位置。
- 可选 `yearline`：复用 `core.market_env.anchor_env` 的严格定义（单锚版）——
  「站上年线 `close > MA250`」且「均线多头顺次排列 `MA5>MA20>MA60>MA250`」
  才判向上；`position` 仍用近 120 日分位，使 W71「大盘非高位」硬门闩口径不变；
  不足 250 根判 `未知`，绝不放行。
- 返回结构与默认函数对齐，`calculate_resonance_score` 无需改动。

### 建议 5：指数滞后

`fetch_index` 允许 DB 指数滞后 1-3 天，个股日 K 到最新交易日，二者可能跨期错配。

- 新增 `index_lag_days(stock_df, index_df)`：个股最新日 − 指数最新日（自然日），
  缺「日期」列或异常诚实返回 `None`。
- **生产实测**：指数最新日 2026-11-03、主流个股 2026-11-06，4000 只样本中
  `lag>3` 为 0 —— 滞后 3 天是常态。因此**默认只诊断、不降级**：结果附
  `指数滞后天数` / `大盘腿降级` 字段，不改任何判定。
- 显式设置 `MYSTERY_RESONANCE_INDEX_MAX_LAG_DAYS=N` 后，仅当 `lag>N` 才把
  大盘腿收紧为 `未知`（不放行），避免跨期错配误判顺势。当前生产 lag=3，
  设 N=3 不触发。

### 建议 7：阈值 / 资金门槛参数化

- `calculate_resonance_score(..., true_threshold=85.0)`：硬编码 85 门闩参数化，
  门闩标签动态渲染（默认仍是「共振评分≥85」，W71 测试兼容）。
- `analyze_capital_flow(..., min_score=8.0, min_volume_ratio=1.5)`：
  「资金 ≥8 或 量比 ≥1.5」隐含门槛参数化。
- 关键：真三振由 6 道 `gates` 取 `all()` 决定，降阈值**只放宽「共振评分」
  这一道**，不会绕过 W71 的「大盘非高位」等硬门闩，不引入高位误报。

### 建议 7：三级共振可过滤

W71 已修复 `三级共振` 的计算（严格个股腿 + 动态归因），但它没有过滤入口。
W72 把它**只读**暴露：`filter_by_signal(results, "three_resonance")` 从
`mystery.resonance.三级共振` 读取，缺字段 / `None` / unknown 一律当 `False`。
不新增 `classify` 返回键，保护 `test_no_signals_default` 的精确字典断言。
CLI：`czsc-mi scan --watchlist --signal three_resonance`。

### 缓存键修复（W23 契约）

`analysis_cache` 键原本只含复权 / `RULE_VER` / DCSF 标志 / czsc 版本 / K 线指纹，
不含口径。若不修，切换 env 后会命中旧缓存，甚至 ma 与 yearline 结果互相污染。
`resonance_cache_tag()` 把**规范化后**的口径拼进 flags：

- 默认（未设任何 env）返回 `''` → flags 逐字不变 → 既有缓存 100% 命中、零失效；
- 开启口径后返回稳定 tag → 独立键空间，不同口径不互相命中；
- 走 `resolve_resonance_options` 归一化，`80` 与 `80.0`、非法值回退都得同一 tag，
  避免无谓 miss。

## 三、开关全表

| 变量 | 默认 | 说明 |
|------|------|------|
| `MYSTERY_RESONANCE_MARKET_MODE` | `ma` | `ma` / `yearline` |
| `MYSTERY_RESONANCE_TRUE_THRESHOLD` | `85` | 真三振共振评分门闩 |
| `MYSTERY_RESONANCE_CAPITAL_MIN` | `8` | 资金活跃 score 门槛 |
| `MYSTERY_RESONANCE_CAPITAL_VR` | `1.5` | 资金活跃量比门槛 |
| `MYSTERY_RESONANCE_INDEX_MAX_LAG_DAYS` | 关闭 | 只诊断；设 N 时 lag>N 收紧大盘腿 |

```bash
# 严格口径 + 阈值 80（仅回测/评估，会改变触发语义）
MYSTERY_RESONANCE_MARKET_MODE=yearline \
MYSTERY_RESONANCE_TRUE_THRESHOLD=80 \
czsc-mi scan --watchlist --no-persist

# 三级共振可过滤（默认可用，无语义变更）
czsc-mi scan --watchlist --signal three_resonance
```

## 四、历史金标对拍（生产库，纯只读）

脚本 `/tmp/w72_replay.py`，数据 `sh.000001` 756 根（2023-09-14 → 2026-11-03）。

**A. 大盘腿口径**（100 个滚动窗口，固定四维全过上下文）

| 口径 | 判「向上」窗口 | 真三振触发 |
|---|---|---|
| `ma`（默认） | 52 | 17 |
| `yearline`（严格） | 43 | 9 |

严格口径更保守（站年线 + 多头顺次排列），触发窗口少约一半。切换会改变信号
语义，故 W72 默认保持 `ma`。

**B. 阈值敏感性**（固定「大盘向上+中位」上下文，资金分数 0~20 → score 80~100）

| 阈值 | 触发（共 21 个样本） |
|---|---|
| 80 | 21（比默认多 5，含 score 80~84） |
| 85（默认） | 16 |
| 90 | 11（比默认少 5） |

阈值确实可调，但降阈值不绕过高位等硬门闩（`gates` 为 `all`），不会引入高位误报。

**C. 指数滞后**：指数 2026-11-03 / 主流个股 2026-11-06 / lag=3。默认只诊断，
设 N=3 时生产当前不触发降级。

## 六、边界与后续

- 本次**不切换任何生产默认**：严格大盘腿、降阈值只作为开关与回测入口。
  若要设为默认，需先定口径、做完整历史回测与模拟交易验证，并评估对
  `RULE_VER` / 评分可比性的影响。
- 未改 `RULE_VER`：默认路径结果与 0.10.30 逐字段一致，既有 analysis_cache
  零失效。
- 诊断字段 `共振口径` / `指数滞后天数` / `大盘腿降级` 为纯增量，旧 job
  缺字段时展示层按缺失处理，不影响既有列。
- 艾略特波浪 / 真三振均为交易过滤规则，不代表信号必然出现；任何口径切换
  都必须经历史回测与模拟交易验证。
