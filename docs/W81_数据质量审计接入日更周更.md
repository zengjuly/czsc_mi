# W81 数据质量审计接入日更/周更（v0.10.40）

## 目标

把已有的 `czsc-mi audit`（只读数据质量巡检）以**可选、非致命**方式接入
`scripts/daily_pipeline.sh` 与 `scripts/weekly_shares.sh`，对换手全 0、
OHLC 异常、重复主键等问题给出告警，避免「0 换手被当成真实缩量」参与
换手分档与风格标签。

## 改动

### 1. `mystery/store/audit.py` — 新增第 7 项检查「换手缺失」

- 口径：**仅查最新一个交易日**（`MAX(substr(date,1,10))`），统计
  `turn IS NULL OR turn<=0` 且 `volume>0` 的行数，不全表扫描。
- 输出键：
  - `latest_trade_date`：最新交易日；
  - `turnover_zero_recent`：该日换手缺失只数；
  - `turnover_zero_ratio`：缺失占比（4 位小数）；
  - `turnover_missing_likely`：占比 >50% 时为 True——判「数据源/股本
    快照缺失」而非个股行为；
  - `samples.turnover_zero_recent`：缺失样本（code, turn）。
- 原 5 项检查行为与返回结构完全不变（向后兼容，旧调用方零回归）。

### 2. `mystery/apps/cli.py` — audit 命令输出新检查项

- 文本输出新增「换手缺失(日期): N 只，占比 R」；
- `turnover_missing_likely=True` 时额外打印 ⚠️ 提示（勿当成真实缩量）；
- `--verbose` 样本键列表加入 `turnover_zero_recent`；`--json` 自动携带。

### 3. `scripts/daily_pipeline.sh` — 可选 audit 步骤（4.5/5）

- 开关：`RUN_DATA_AUDIT`（**默认 0 关闭**；生产库 900 万行全量审计约 4 分钟）；
- `RUN_DATA_AUDIT=1` 时 `timeout ${DATA_AUDIT_TIMEOUT:-900} czsc-mi audit
  --period daily`，输出写 `<报告目录>/audit_日期.log`，摘要行回显；
- 发现「疑似数据源缺失」时状态标 `warn`；失败/超时标 `fail`，**不阻塞主流程**；
- `pipeline_status.json` 新增 `"data_audit": "skip|ok|warn|fail"` 字段
  （旧键不变，日报页脚/飞书读取方兼容）。

### 4. `scripts/weekly_shares.sh` — 可选 audit（铺盘后、QA 前）

- 同样由 `RUN_DATA_AUDIT`（默认 0）控制；失败/超时仅写日志告警，
  **不影响铺盘结果与脚本退出码**。

## 不做的事（约束）

- 不改评分/信号/`RULE_VER`；core 零改动；audit 保持只读（全 SELECT）。
- 审计不自动修复任何数据，只告警；修复仍走既有 `sync-turnover
  --backfill-days` 等通道。

## 生产背景（2026-11-09 实测）

- 生产库 daily 约 923 万行，全量 audit 约 239 秒——故默认关闭、按需开启；
- 存量噪声：`volume_no_amount` 11.9 万条、`date_gaps_gt_7d` 7.9 万条
  （历史数据，审计时以趋势对比为主，不必逐条清理）。

## 验收

- `tests/test_w81_audit_pipeline.py` 3 例：
  换手缺失检出/占比告警、正常数据不误报、两脚本护栏文本断言；
- 全量 `pytest -m "not integration"` 全绿。

## 回滚

audit.py / cli.py / 两个脚本均为独立增量，`git revert` 单提交即可；
关闭 `RUN_DATA_AUDIT`（或不设）即回到旧行为。
