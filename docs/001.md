## W6. 缠论分：先可解释，默认仍关闭

**不要**在本轮把 `MYSTERY_CHAN_ENABLED` 默认改成 1。  
**不要**只靠末笔 ±10 冒充缠论体系。

在 `core/scorer.py` 把 `chan_score` 收成可测、可解释的规则，仍然只用 `ChanStructure`（core 不碰 czsc 对象）：

建议（实现时写成纯函数 + 单测，权重保持 0.20）：

| 条件 | 加减 |
|---|---|
| 无日线结构 | 50 |
| `last_bi_dir==up` 且 `last_bi_confirmed` | +10 |
| `last_bi_dir==down` 且 confirmed | -10 |
| 日线 `in_zs` | +5 |
| 同时存在 `1w` 且周线末笔与日线同向 | +8 |
| 日周反向 | -8 |
| 分数夹紧 [0, 100] | |

年线否决逻辑不动：`年线滤网 is False` → 总分 0。

`combine(..., chan_enabled=False)` 的单测保持：分数等于 Mystery 原分。  
打开时的混合公式不变：`round(0.55*s_m + 0.25*s_r + 0.20*s_c, 1)`。

Web 个股页：展开 `chan['1d']` / `chan['1w']` 的 `last_bi_dir`、`in_zs`、`n_fx`、`engine_ver`。只读 `AnalysisResult`，不算分。

**验收：** `test_combine_chan_off_unchanged`、`test_combine_p4_veto` 仍绿；新增日周同向/反向测。
