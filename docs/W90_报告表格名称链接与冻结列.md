# W90 · 报告表格「详情链接挂到股票名称」+「冻结名称列」

## 需求

> 分析报告表格中的详情链接加到股票名称上，并冻结股票名称列。

「分析报告表格」有两类载体，二者「冻结列」实现路径完全不同，故同步改造、口径一致：

| 载体 | 详情链接现状 | 冻结列现状 |
|---|---|---|
| 网页「扫描结果」表 | 「详情」为独立列（LinkColumn，新标签打开） | 此前未冻结 |
| Excel「汇总报告」 | 无（W14 起取消代码列超链接） | `freeze_panes="A2"` 仅冻首行 |

## 改造内容

### 1. 网页扫描结果表（`mystery/apps/web/views/scan.py`）

- **纯函数 `_scan_table_data` 字段不变**（既有测试 `test_scan_table_shows_signal_flags` 零改动）：仍产出含「详情」URL 的字典行。
- 新增渲染层纯函数 `_name_link_rows(table_data)`：
  - 把「详情」列的 URL 挂到「名称」列值，末尾追加 `&_n=<股票名>`；
  - 名称里中文**原样保留**（`display_text` 正则按原始串匹配回显，避免 `%XX` 乱码），仅对 `& # ? = % 空白` 等结构性字符 URL 编码；
  - 移除独立「详情」列；输入不被修改（逐行浅拷贝）。
- 新增 `_scan_table_column_config()`：
  - 「名称」=`LinkColumn(pinned=True, display_text=_NAME_DISPLAY_RE)`：`display_text` 正则 `[?&]_n=([^&]+)` 把股票名回显为可点击文字，实现「点名称即进详情」；
  - 因 glide-data-grid 冻结的是**左侧连续前缀列**，名称是第 2 列，故「序号」一并 `pinned=True`，保持列序且名称稳定落冻结区；
  - 不再为「详情」列配置。
- 导航/鉴权参数（`nav_key` / `nav_idx` / `at`）原样保留在 URL，跨标签导航不破坏；详情页只读 `stock` 参数，`_n` 被忽略。

> 技术边界：Streamlit ≥1.40 的 `Column(pinned=True)` 是**原生列冻结**（"stay visible on the left no matter where the user scrolls"），非 CSS 兜底，效果等同 Excel 冻结窗格。

### 2. Excel 汇总报告（`mystery/apps/reports/excel_report.py`）

- 新增可配置纯函数 `stock_detail_url(symbol, base_url=None)`：
  - `base_url` 缺省依次取环境变量 `MYSTERY_WEB_BASE_URL` → `http://127.0.0.1:18601/`；
  - symbol 做 URL 编码（保留 `.`）；base 是否带 `?` 智能选 `?`/`&`；
  - 详情页 query 直达只需 `?stock=<symbol>`，离线 xlsx 用浏览器已登录 session（cookie）鉴权，不依赖会过期的时效 token。
- `_build_buffer` 写盘时：
  - `freeze_panes` 由 `"A2"` 改为 **`"B2"`**（冻结首行 + 名称列 A）；
  - 名称单元格（A 列）叠加详情超链接（蓝色 `0563C1` + 下划线），文字仍为股票名；
  - 代码列（B 列）仍无链接，既有回归 `test_no_code_hyperlink` 不变。
