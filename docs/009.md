## W28a — QA 第二口径

**问题**：现行覆盖率 = 近 20 日所有 K 根中 `turn` 非空比例。`as_of` 落在窗口中后段时，前半段依法不填，46.4% 会被当成派生失败。

**做**

`turnover_qa_stats`（及日报 QA 行）增加只读字段：

```text
as_of_min / as_of_p50 / as_of_max
window_start        # 近 20 交易日起点
skipped_before_asof # 已有，落到日报
no_shares
fillable_rows       # 有快照且 date >= as_of 且有 volume 的 K 根
filled_rows         # 其中 turn 非空
fillable_coverage   # filled_rows / fillable_rows
```

日报两行保持【自选】/【全市场】，每行附：

```text
覆盖率 x% | 可填覆盖率 y% | 快照 as_of_min~max | skipped_before_asof=n
```

- **可填覆盖率**：看派生健不健康（目标自选 ≥95%）。
- **覆盖率**：看 `chip_low` 窗口够不够（随交易日和回填上升）。

`weekly_shares.sh` 结尾 QA 同样打出自选 + 全市场，不要只打 `n_with_shares`。

**落点**：`db.turnover_qa_stats` 或 `sync_turnover` 汇总、日报 Excel 页脚 / HTML `.qa`、`test_turnover_qa.py`。

**验收**：夹具里 as_of=窗口末日时，覆盖率低、`fillable_coverage` 高；无新假 `turn`。

**不做**：改分母把「不能填的根」算进已覆盖。

## W28b — 周脚本可失败

**问题**：`weekly_shares.sh` 两步都是 `|| echo`，全市场中断后 cron 仍绿；QA 只打全市场一行。

**做**

```text
1/2 czsc-mi sync-shares --watchlist --fresh-skip-days 6
2/2 czsc-mi sync-shares --fresh-skip-days 6
3 写 weekly_shares_status.json
{date, watchlist_with_shares, market_with_shares, exit}
```

退出码：
- 自选 `watchlist_with_shares` 低于「自选只数 × 0.9」→ `exit 1`
- 全市场 `market_with_shares` 低于可配置阈值（默认 1000，环境变量 `WEEKLY_SHARES_MARKET_MIN`）→ `exit 1`
- 允许低于全 A：停牌/无竞价价缺票；阈值防「只跑完自选却报成功」

断点：重跑仍靠 `--fresh-skip-days 6` 跳过今日已写票。`--force` 不进该脚本。

周一日报若存在 `weekly_shares_status.json`（7 日内），页脚加：`上周铺盘 market_with_shares=N`。

**落点**：`scripts/weekly_shares.sh`、可选读 status 的日报组装、一则壳测或文档约定阈值。

## W28c — 运维（可无代码先做）

```text
# crontab 示例（主机路径以 .stockrc 为准）
0 10 * * 0 /path/to/czsc_mi/scripts/weekly_shares.sh
# 自选已有 86 份快照：先铺近端 turn（不越 as_of）
czsc-mi sync-turnover --watchlist --backfill-days 20
# 周日全市场快照成功后再：
czsc-mi sync-turnover --backfill-days 20
```

`daily_pipeline.sh` **不传** `--backfill-days`。18:00 仍只填当天。

**验收**
- crontab -l 看得到周脚本。
- 自选 `fillable_coverage` 升到高位；`watchlist_turn_20_coverage` 高于 46.4%（剩余缺口 ≈ `skipped_before_asof`）。
- 周任务后 `market_with_shares ≫ 86`。
