# W86：指数 / 板块 / 个股的主力建仓与吸筹分析

> 版本 v0.10.44 · 需求：「增加 关注的或者 指数 板块 个股的主力建仓与吸筹的分析」

## 一、理论依据（原论 `docs/mistery20260524.md`）

- 【筹码博弈——股市的终极真相】：「价格是表象，筹码在谁手里才是底层逻辑」。
- 【主力行为学】【主力的吸筹方式】：震荡 / 打压 / 拉高 / 借利空四种吸筹手法。
- 【小阳建仓】：低位 + 连续小阳 + 量温和放大但不突兀 + 波动可控。
- 【低位诱空】【震仓与出货】：低位放量下跌是**打压吸筹**而非高位派发。
- 【什么是筹码结构 / 集中度 / 关于筹码峰】、【筹码归编】：筹码沉淀集中是蓄势。
- 【所有的底，绝不是越低越好，而是资金筑底】：**底部是主力初步建仓区间，属观察区间而非买点**；需等主升雏形 + 回撤极度缩量、抛压衰竭才是参与时点。

## 二、新增核心模块 `mystery/core/accumulation.py`（纯函数、零 IO）

统一输出 JSON 可序列化的吸筹研判 dict：

| 字段 | 含义 |
|---|---|
| `level` / `level_cn` | 强吸筹 / 疑似吸筹 / 观察 / 非吸筹 / 数据不足 |
| `stage` | 吸筹 / 打压吸筹 / 洗盘 / 拉升 / 派发 / 震荡（互斥判据） |
| `retrace_pct` | 较近 120 根高点的回撤比例（%） |
| `near_low` / `above_year` | 区间低位 / 年线位置 |
| `vol_trend` / `vol_state` | 近 5 日均量 ÷ 前 20 日均量 → 极度缩量 / 缩量沉淀 / 常量 / 温和放量 / 明显放量 |
| `chg_20d` / `amp20` | 20 日涨跌 / 20 日振幅 |
| `evidence` / `conclusion` | 四层证据链逐条 + 一句话结论（含「观察区间非买点」提示） |

### 四层证据链打分

| 层 | 判据 | 分 |
|---|---|---|
| 位置 | 回撤 ≥15%（`LOW_RETRACE`，与 `core/scan_signals.CHIP_LOW_RETRACE` 同源）或区间低位 | +30 |
| 量能 | 缩量沉淀 / 温和放量 | +25（极度缩量 +12） |
| 横盘 | 20 日涨跌 ≤5% | +15 |
| 低波动 | 20 日振幅 <20% | +8 |
| 阶段 | 吸筹 / 打压吸筹 / 洗盘 | +20 / +12 / +8 |
| 筹码（个股） | `chip_low` / 换手 <2% 或 3~5% 吸筹区 | +20 / +8 |

### 三道护栏（避免误判）

1. **派发必须高位**：`near_top and 放量滞涨/价跌量增` 才判派发。低位放量下跌按原论判「打压吸筹 / 低位诱空」，绝不误判成高位出货。（实测电力板块因此从误判派发改为打压吸筹。）
2. **区间相对位置判据**：`near_top` / `near_low` 用 `(price-lo)/(hi-lo)` 而非 `0.9*hi` / `1.1*lo` 硬阈值——后者在横盘序列（hi≈lo≈price）会恒为真，把横盘误判成高位或低位。
3. **严格大盘腿降级**：跌破年线（`above_year=False`）时，即便证据分够也不判「强吸筹」，降级为「疑似吸筹 / 观察」，并在证据与结论中明示。

「强吸筹」额外要求 低位 + 横盘 + 有效量能同时成立。派发 / 拉升直接排除。

## 三、三类对象接入

| 对象 | 通道 | 口径 |
|---|---|---|
| **各大指数**（W84 8 大宽基） | `services/index_analysis.py` 挂 `accumulation` + `accumulation_level` | 纯价格（`analyze_accumulation`），与 W84 年线同源同一份 closes |
| **关注行业板块**（W85） | `services/sector_analysis.py` 挂 `accumulation` | 纯价格 + 板块强度分；强相关个股附带吸筹等级 |
| **个股 / 关注标的** | `apps/reports/result_fields.py::accumulation_of` | 优先读 payload 顶层 `accumulation`；历史结果无该字段则走 `accumulation_from_result` **只读 `to_dict()` 推导**（复用 `mystery.stage.stage` / `chip_low` / `turnover_20` / `price` / `high_120` / `年线滤网`），不取数、不重算评分 |

个股「换手缺失」三态保持治理口径：`chip_low_unknown=True` 时明确提示「禁止判定低换手」，`chip_quiet` 提示「高位缩量不计吸筹」，绝不把 unknown 当 True、绝不伪造 0。
