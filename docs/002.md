## W4-A 个股页缠论图增强（plotly 自绘，0.6.0）

### 背景

czsc 1.0.1 的 `plot_czsc`（lightweight-charts）`MainPane` 只有 `sma5/sma20`
两个均线字段且**不画中枢区间**（`_data.py` 的 `MainPane` 无 ZS 字段）。用户
反馈三问题：无法切周线/月线、K 线图无中枢区间、无 MA 5/10/20/55/233/610。

### 做什么

1. `adapters/czsc_adapter.py`：
   - 新增 `plot_figure(series, tail_bars=400, theme="light", ma_periods=(5,10,20,55,233,610))`
     → plotly Figure（CZSC 对象只在 adapter 内重建，跨层仍只传 core dataclass）：
     K线 + 6 条 MA + 分型虚线 + 笔实线 + 中枢矩形（ZG-ZD 填充框 + GG-DD 虚线
     外框 + "中枢 N笔" 标注）+ 成交量 + MACD(12,26,9,×2，czsc 首值种子 EMA 口径)。
   - MA/MACD 在全集 K 线上计算再按尾窗截取（长周期均线有暖机值）。
   - `plot_html` 改为 `plot_figure(...).to_html(include_plotlyjs="cdn")` 兼容壳。
2. `apps/web/app.py`：
   - `_plot_cache(symbol, freq)` 按 (symbol, freq) 缓存 Figure；周/月走
     `fetch_bars` 日K重采样，不重新分析。
   - 缠论卡加「K线周期」radio（日线/周线/月线），`st.plotly_chart` 原生渲染
     （不再用 `stc.html` iframe，省外网 CDN 依赖）。
   - 移除 session 里 `stock_plot`（渲染时按需取缓存）。
3. `services/analyze.py`：`_analyze_chan` 补 `1M` 结构（只展示；`scorer.chan_score`
   只读 1d/1w，评分不变）。

### 不要做

- 不修改 czsc 源码（只读参考）；不复制第二套缠论识别。
- 不把 `plot_figure` 返回的 Figure 之外的 czsc 对象传出 adapter。

### 验收

- `pytest -m "not integration" -q` 全绿（新增 3 个 plot_figure 测试）。
- 个股页 chan 开启：日/周/月三周期均出图；图上 6 条 MA 与中枢矩形可见；

## W5-A 个股页技术面明细（technical 快照，0.7.0）

### 背景

用户反馈个股页缺 均线排列分析 / 破五反五 / 量价分析 / 筹码分析 / 换手率 /
财务指标 / 多周期分析。这些指标 core 层其实都已计算（indicators 57 列 +
MysteryLogic.check_po5_fan5 / technical_detail_capture / weekly_anchor_check /
_analyze_cycle_box），但 enrich 后的 DataFrame 被丢弃，AnalysisResult 只带
聚合 dict，Web 无从展示。

### 做什么

1. `core/models.py`：`MysteryBreakdown` 加展示字段 `technical: Dict`（不进评分，
   §3.3 展示字段例外）。
2. `core/pipeline.py`：`build_technical_snapshot()` 在 include_detail 时产出：
   - ma：排列状态（多头/空头/混合）+ 多头排列强度 + MA5/10/20/60/250 + MA5斜率 + 信号
   - po5：`check_po5_fan5` 完整判定（破五天数/MA20斜率/原因）
   - chip：`technical_detail_capture`（筹码集中度/数值/趋势）
   - volume_price：量比/量价配合度/OBV信号/成交量信号/动能状态/涨跌幅
   - turnover：换手率/区域/MA5/10/20/相对位置
   - multi_period：周/月趋势（旧仓 MA 排列口径）+ 周/月箱体（复用 platform）+
     周线锚定
3. `mystery_rules.technical_detail_capture`：换手率全 0/缺失时标「数据缺失」，
   不伪造「高度集中」（ths/tdx 常缺 turn，已知数据坑）。
4. `apps/web/app.py`：`_render_technical()` 渲染「分析明细」expander（6 分段）；
   财务指标补 EPS(TTM)/股息率/净利率/毛利率（db.get_financial 已有字段）。

### 验收

- `pytest -m "not integration" -q` 全绿（新增 2 个 technical 快照测试）。
- 真实 600519：technical 六段均有数值；换手率缺失时筹码显示「数据缺失」。
- AppTest 预置 AnalysisResult → 六分段 markdown 渲染 + 财务第二行 metric 出现。
